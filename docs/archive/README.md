# Documentation Archive

This directory preserves superseded documentation, completed work items, dated
release checklists, and point-in-time audits. It is intentionally **not** part
of the current contributor or user documentation path.

Archived documents retain their technical claims for historical context.
Relative links are rebased when files move. They are not maintained against the current source tree.
When an archived document conflicts with current code, tests, or a document
outside this directory, the current source and non-archived documentation win.

| Directory | Contents |
|---|---|
| `architecture/` | Superseded architecture maps and generated analyses. |
| `audits/` | Completed audit reports and dated audit outputs. |
| `designs/` | Completed or superseded design rationale. |
| `handoffs/` | Session handoffs, worklogs and outbound drafts. |
| `local/` | Ignored local-only reports, outside tracked publication. |
| `notes/` | Superseded scratch notes and old findings. |
| `plans/` | Completed programs and superseded roadmaps. |
| `sage/` | Previous SAGE architecture and pipeline analyses. |
| `specs/` | Delivered specifications and dated gates. |
| `readmes/` | Previous repository README snapshots. |
| `releases/` | Version-specific release checklists. |
| `reports/` | Coverage, working-tree, and other point-in-time reports. |
| `work-items/` | Closed issue notes and completed backlog material. |

For current documentation, start at [the documentation index](../README.md).
