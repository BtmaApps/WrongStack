## Compatibility blockers found in this expansion

- Expo SDK 57 documents RN 0.86 and React 19.2.3; RN 0.87.1/React 19.3.0 are
  independently newer. Choose the supported Expo matrix or a verified bare RN
  path; do not silently mix versions or suppress validation.
- Angular compiler-cli 22.2.2 declares TypeScript >=6.0 <6.1; TypeScript 7.0.2
  is outside the supported peer range.
- Prisma latest is 8.0.0-rc.22; highest published non-deprecated stable is 7.10.0,
  matching the checked stable client. Spring/.NET indexes contain milestone/RC
  targets that must also be excluded from stable selection.
- Nginx stable and mainline are separate published channels.
- Flutter archive machine-readable reads were unavailable. The 3.47.5 release
  tag and 3.47 stable documentation were confirmed. Re-resolve latest patch from
  the archive before installation rather than inventing it.
- MongoDB stable series was confirmed; exact server patch and managed provider
  eligibility remain deployment-time checks.

## Compatibility observations

- Motion Canvas vite-plugin 3.17.2 declares Vite 4.x or 5.x. Latest Vite 8.3.4
  is outside that peer range. Keep this blocker visible; do not bypass it with force.
- React DOM 19.3.0 requires React ^19.3.0; upgrade the pair.
- R3F 9.8.1 declares React >=19 <19.4, compatible with the checked 19.3.0.
- Vitest 5.0.3 requires supported Node ranges and matching 5.0.3 coverage plugins.
- Wrangler 4.149.0 requires Node >=22.0.0.
- Node Current is not automatically LTS. Choose latest stable for the requested
  target and state a deployment runtime restriction when it prevents adoption.

The entrypoint describes cross-ecosystem lookup; this snapshot does not claim
every package or hosted model has been checked. Unavailable sources stay unknown.
